# opinion-map · 舆论反应模式库 + 经验沉淀

**用途**：预测模式的底库——新事件来了，按事件类型调模板，预测网上会怎么吵。
**核心原则**：模板是"起点"不是"答案"；只记录实测验证过的经验，不记录"觉得会这样"。
**维护**：每次跑完真实观点地图，按 SKILL.md 三·七 经验沉淀流程更新本文件。

---

## 模式库（按事件类型）

### 类型① 公权力 / 特权事件
**触发特征**：公职人员/权力身份介入公共或私人事务
- 标准派系：
  1. 特权批判派（公权私用、破坏公平）——主流
  2. 人之常情派（为孩子/家人铺路正常，可能手滑误发，反对上纲上线）
  3. 制度边界反思派（该不该亮身份、边界在哪）
  4. 追问追责派（身份是否属实、纪检是否介入）
- 常见分歧：动机（刻意炫权 vs 手滑误发）
- 常见空白：制度视角（怎么避免）、一线当事人（老师/被夹住的人）
- 验证状态：✅ 已验证（保定一中家长群事件 2026-09-03）

### 类型② 政策 / 民生新规
**触发特征**：官方新政策、新标准、行业改革落地
- 标准派系：
  1. 期待支持派（方向对、终于解决痛点）
  2. 疑虑派（治标不治本、换个壳、新瓶旧酒）——主流
  3. 执行悲观派（落地难、受益人群用不上）
  4. 政策治理派（官方背书、成果已见）——声量大但情感卷入低
- 常见分歧：能不能根治 vs 只是表面功夫
- 常见空白：最大受影响但最不发声的群体（老人/基层）、政策的最大受损方（被改革的利益方）
- 验证状态：✅ 已验证（告别机顶盒 2026-09-03）

### 类型③ 医疗 / 健康 / 科学争议
**触发特征**：涉及医学、健康、科学与传统/大众认知冲突
- 标准派系：
  1. 科学证据派（RCT、证据等级、可证伪）——理性主流
  2. 经验传统派（亲身有效、传承必有用）
  3. 中间循证派（有效成分+不科学理论分离）
  4. 受害/风险派（被延误、副作用、被骗）
  5. 政策/官方派（守正创新、去伪存真）
- 常见分歧：认识论（什么算证据——RCT vs 个人体验）
- 常见空白：一线从业者内部的分歧与难处、受害者的真实代价、产业链利益方
- 验证状态：✅ 已验证（中医无用论 2026-09-03）

### 类型④ 名人 / 明星 / 公众人物事件
**触发特征**：名人争议、纠纷、翻车、风评变化
- 标准派系：
  1. 批判派（道德/人品审判）——主流
  2. 能力/成绩派（事业成就、专业能力与私德分开）
  3. 路人吃瓜派（当娱乐看，不站队）
  4. 粉丝/支持派（辩护、洗白）
  5. 现象分析派（分析营销、公关逻辑，不评道德）
- 常见分歧：人品 vs 能力；成功 vs 原罪
- 常见空白：不同人群眼中的他（散户/圈内/监管/合作方/本人叙述）、生态数据 vs 情绪标签
- 验证状态：✅ 已验证（孙宇晨 2026-09-03）

### 类型⑤ 性别 / 家庭 / 情感事件
**触发特征**：涉及性别对立、家庭分工、婚恋纠纷
- 标准派系（初始模板，未验证）：
  1. 性别对垒派（各护各的群体，指认对方双标）
  2. 个体叙事派（当事人视角，强调具体情境不是立场）
  3. 结构反思派（制度/文化/社会根源）
  4. 中立调和派（拒绝站队、反对上纲上线、要求看证据）
- 常见分歧：个体问题 vs 结构问题（"这是个人渣还是社会病"）
- 常见空白：当事人真实处境、被裹挟的第三方（孩子/家人/同事）、男性或女性被忽视的一侧
- 验证状态：⏳ 待验证

### 类型⑥ 商业 / 科技 / 行业事件
**触发特征**：公司、产品、技术、行业动态
- 标准派系（初始模板，未验证）：
  1. 利好支持派（机会、进步、股价/市场利好）
  2. 质疑风险派（泡沫、垄断、隐私、安全性、监管风险）
  3. 从业者专业派（懂行的技术/行业视角，常与大众视角冲突）
  4. 吃瓜围观派（贵不贵、与我何干、段子化）
- 常见分歧：创新价值 vs 风险成本（"是未来还是割韭菜"）
- 常见空白：一线从业者的真实处境（裁员/加班/转型）、被忽略的用户群体（老人/弱势）、产业链上下游利益方
- 验证状态：⏳ 待验证

### 类型⑦ 教育事件
**触发特征**：涉及学校、家长、学生、教育政策、师生冲突
- 标准派系（初始模板，未验证，可复用类型①③特征）：
  1. 教育公平派（特权/资源不公）
  2. 家长共情派（养娃焦虑、为孩子好）
  3. 从业者派（老师/学校视角，常被忽略）
  4. 制度反思派（评价体系/家校关系/政策）
- 常见分歧：个体责任 vs 制度问题
- 常见空白：学生本人的声音（被家长和老师共同代表）、一线老师的处境
- 验证状态：⏳ 待验证

### 类型⑧ 灾难 / 事故事件
**触发特征**：灾害、事故、伤亡、公共安全
- 标准派系（初始模板，未验证）：
  1. 哀悼祈福派（共情、点蜡烛，主流但低争议）
  2. 追责派（谁负责、官方回应是否及时）——情绪最强
  3. 预警反思派（为什么没防住、制度漏洞、吹哨人）
  4. 救援进展派（最新动态、感人事迹、正能量）
- 常见分歧：天灾 vs 人祸（不可抗力 vs 失职）
- 常见空白：幸存者/遇难者家属的真实声音（常被媒体叙事简化）、基层救援人员的视角、后续赔偿与心理重建
- 验证状态：⏳ 待验证

## 经验沉淀区（更新日志）

### 2026-09-03 四次实测沉淀
- 类型①（公权力）：补充"人之常情派"存在且是第二大声量；空白角度=制度视角+老师视角 → 已入模板
- 类型②（政策/民生）：疑虑派占主流（治标不治本）；最大空白=不发声的受益群体（老人本人）与受损方（厂商）→ 已入模板
- 类型③（医疗/科学）：核心分歧在"认识论"（什么算证据）而非立场本身；从业者内部理性分歧是最大空白 → 已入模板
- 类型④（名人）：评价必须按"人群"拆（散户/圈内/监管/吃瓜/本人五套评价）；"能力认同"维度不能并入"批判/支持"二分 → 已入模板

### 预测准确性经验（先验）
- 强预测：会出现哪几派、每派核心主张（模式稳定）
- 弱预测：哪派声量最大、风向走势（受事件细节、名人效应、平台算法影响大）
- 待积累：更多非争议型话题（商业/行业/教育）实测后补验

### 预测准确率跟踪（越用越聪明的量化）
每次"预测 → 发酵 → 校验"后，记录该事件类型的预测命中率：

| 事件类型 | 预测派系数 | 实际派系数 | 命中（派系对上了） | 漏掉 | 多预测 | 日期 |
|---|---|---|---|---|---|---|
| 示例：公权力 | 4 | 4 | 3/4 | 1（人之常情派没预到） | 0 | 2026-09-03 |

统计规则：
- **命中**：实际出现且被预测到的派系 / 实际出现的派系总数
- **漏掉**：实际出现但没预测到的新派系（→ 按经验沉淀"新派系"扩充模板）
- **多预测**：预测了但实际没出现的派系（→ 可能是"该派只在小众场景出现"或"模板过度泛化"，考虑弱化）
- 命中率 < 60% 的类型 → 标"模板不可靠"，优先实测修正；>80% → 标"模板成熟"
- 长期跟踪，每个类型有数据说话——这就是"越用越聪明"的量化证明
