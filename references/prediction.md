# opinion-map · 舆论反应模式库 + 经验沉淀

**用途**：预测模式的底库——新事件来了，按事件类型调模板，预测网上会怎么吵。
**核心原则**：模板是"起点"不是"答案"；只记录实测验证过的经验，不记录"觉得会这样"。
**维护**：每次跑完真实观点地图，按 SKILL.md 三·七 经验沉淀流程更新本文件。

---

## 模式库（按事件类型）

### 类型① 公权力 / 特权事件
**触发特征**：公职人员/权力身份介入公共或私人事务
- 标准派系：
  1. 特权批判派（公权私用、破坏公平）——主流
  2. 人之常情派（为孩子/家人铺路正常，可能手滑误发，反对上纲上线）
  3. 制度边界反思派（该不该亮身份、边界在哪）
  4. 追问追责派（身份是否属实、纪检是否介入）
- 常见分歧：动机（刻意炫权 vs 手滑误发）
- 常见空白：制度视角（怎么避免）、一线当事人（老师/被夹住的人）
- 验证状态：✅ 已验证（保定一中家长群事件 2026-09-03）

### 类型② 政策 / 民生新规
**触发特征**：官方新政策、新标准、行业改革落地
- 标准派系：
  1. 期待支持派（方向对、终于解决痛点）
  2. 疑虑派（治标不治本、换个壳、新瓶旧酒）——主流
  3. 执行悲观派（落地难、受益人群用不上）
  4. 政策治理派（官方背书、成果已见）——声量大但情感卷入低
- 常见分歧：能不能根治 vs 只是表面功夫
- 常见空白：最大受影响但最不发声的群体（老人/基层）、政策的最大受损方（被改革的利益方）
- 验证状态：✅ 已验证（告别机顶盒 2026-09-03）

### 类型③ 医疗 / 健康 / 科学争议
**触发特征**：涉及医学、健康、科学与传统/大众认知冲突
- 标准派系：
  1. 科学证据派（RCT、证据等级、可证伪）——理性主流
  2. 经验传统派（亲身有效、传承必有用）
  3. 中间循证派（有效成分+不科学理论分离）
  4. 受害/风险派（被延误、副作用、被骗）
  5. 政策/官方派（守正创新、去伪存真）
- 常见分歧：认识论（什么算证据——RCT vs 个人体验）
- 常见空白：一线从业者内部的分歧与难处、受害者的真实代价、产业链利益方
- 验证状态：✅ 已验证（中医无用论 2026-09-03）

### 类型④ 名人 / 明星 / 公众人物事件
**触发特征**：名人争议、纠纷、翻车、风评变化
- 标准派系：
  1. 批判派（道德/人品审判）——主流
  2. 能力/成绩派（事业成就、专业能力与私德分开）
  3. 路人吃瓜派（当娱乐看，不站队）
  4. 粉丝/支持派（辩护、洗白）
  5. 现象分析派（分析营销、公关逻辑，不评道德）
- 常见分歧：人品 vs 能力；成功 vs 原罪
- 常见空白：不同人群眼中的他（散户/圈内/监管/合作方/本人叙述）、生态数据 vs 情绪标签
- 验证状态：✅ 已验证（孙宇晨 2026-09-03）

### 类型⑤ 性别 / 家庭 / 情感事件
**触发特征**：涉及性别对立、家庭分工、婚恋纠纷
- 标准派系（初始模板，未验证）：
  1. 性别对垒派（各护各的群体，指认对方双标）
  2. 个体叙事派（当事人视角，强调具体情境不是立场）
  3. 结构反思派（制度/文化/社会根源）
  4. 中立调和派（拒绝站队、反对上纲上线、要求看证据）
- 常见分歧：个体问题 vs 结构问题（"这是个人渣还是社会病"）
- 常见空白：当事人真实处境、被裹挟的第三方（孩子/家人/同事）、男性或女性被忽视的一侧
- 验证状态：⏳ 待验证

### 类型⑥ 商业 / 科技 / 行业事件
**触发特征**：公司、产品、技术、行业动态、**行业监管整治行动**
- 标准派系（已验证，基于"网信办整治AI应用乱象"事件 2026-09-03）：
  1. 利好支持派（机会、进步、规范利好长期）→ 监管场景变体：**支持整治派**（乱象该治、为生态清场）——主流
  2. 质疑风险派（泡沫、垄断、隐私、安全性、监管风险）→ 监管场景变体：**治理代价警惕派**（合规成本/误伤/创新受限）——主流叙事下被压制，技术圈存在
  3. 从业者专业派（懂行的技术/行业视角，常与大众视角冲突）→ 监管场景变体：**边界细则派**（区分侵权魔改与合法二创，别一刀切）
  4. 吃瓜围观派（贵不贵、与我何干、段子化）→ 监管场景变体：**中性观察派**（看行业洗牌、治理常态化）
- 监管整治类特有补充（实测发现）：
  - **纯反对整治的强派系几乎缺席**；反方以"代价承担者"形式存在（中小公司合规困境/被误伤创作者），声量集中在技术圈
  - **平台分布规律**：官方+点赞声音在新闻端和短视频评论区；代价/细则声音在技术社区+知乎——大众端几乎看不到反对声，技术圈真实存在（派系分裂）
- 常见分歧：创新价值 vs 风险成本（"是未来还是割韭菜"）；监管场景=治理力度 vs 治理代价（该不该治无争议，成本由谁承担才是分歧）
- 常见空白：一线从业者的真实处境（裁员/加班/转型）、被误伤的真人创作者（手写/手绘被AI误判封号）、"监管=头部护城河"（没人直说）、沉默的大多数用户
- 新品发布类变体（实测 2026-09-04，GPT-6 Astra）：
  - 标准四派 + **安全风险派**（敏感能力产品特有）+ **价格性价比派**（贵/门槛）+ **可监控性悖论派**（对齐提升但可解释性下降——带自主/安全能力产品的新分裂轴）
  - 发布当天形态：官方里程碑叙事+媒体共振=主流窗口；质疑派用第三方榜单/独立环境反制官方跑分；安全讨论从"对齐做得好"转向"更难监控"
  - 平台规律：X=一手实测+安全圈；知乎/B站=技术解读与质疑；微博/公众号=情绪玩梗（价格话题）；科技媒体=官方叙事
  - 常见空白：普通用户（未开放则失声）、竞争对手官方回应、监管反应、被影响从业者本人
- 验证状态：✅ 已验证（网信办整治AI应用乱象 2026-09-03；旗舰新品发布 GPT-6 Astra 2026-09-04）

### 类型⑦ 教育事件
**触发特征**：涉及学校、家长、学生、教育政策、师生冲突
- 标准派系（初始模板，未验证，可复用类型①③特征）：
  1. 教育公平派（特权/资源不公）
  2. 家长共情派（养娃焦虑、为孩子好）
  3. 从业者派（老师/学校视角，常被忽略）
  4. 制度反思派（评价体系/家校关系/政策）
- 常见分歧：个体责任 vs 制度问题
- 常见空白：学生本人的声音（被家长和老师共同代表）、一线老师的处境
- 验证状态：⏳ 待验证

### 类型⑧ 灾难 / 事故事件
**触发特征**：灾害、事故、伤亡、公共安全
- 标准派系（初始模板，未验证）：
  1. 哀悼祈福派（共情、点蜡烛，主流但低争议）
  2. 追责派（谁负责、官方回应是否及时）——情绪最强
  3. 预警反思派（为什么没防住、制度漏洞、吹哨人）
  4. 救援进展派（最新动态、感人事迹、正能量）
- 常见分歧：天灾 vs 人祸（不可抗力 vs 失职）
- 常见空白：幸存者/遇难者家属的真实声音（常被媒体叙事简化）、基层救援人员的视角、后续赔偿与心理重建
- 验证状态：⏳ 待验证

### 类型⑨ 职场 / 劳动事件
**触发特征**：裁员、欠薪、职场霸凌/冷暴力、劳动仲裁纠纷（区别于类型⑥：⑥是公司/产品/行业动态，⑨是劳资关系纠纷）
- 标准派系（已验证，基于"845个工作群"事件 2026-09-03）：
  1. 打工人共情派（同情+情绪共鸣，"太羞辱/硬气解气"）——主流，抖音最重
  2. 企业批判派（软裁员=变相辞退、规避补偿，必须谴责）——主流，官媒
  3. 制度反思派（个案赢了不够，要制度硬约束）——重要，官媒
  4. 普法维权派（教人怎么维权：别裸辞、留证据、走仲裁）——重要，抖音律师
  5. 企业管理派（或为信息安全/管理常规操作）——小众，反方弱、几乎被主流情绪压制
- 常见分歧：公司行为定性（恶意软裁员 vs 可理解的管理操作）；维权胜利意义（个案爽文 vs 系统性困局警示）
- 常见空白：HR/执行者的被裹挟处境、企业"违法成本账"、组织群治理/管理失效（如"845个群"）、沉默不维权者的心理
- 平台特征（实测发现）：功能分化明显——抖音=情绪共鸣+普法双主场，官媒=制度反思；反方声音几乎缺席
- 验证状态：✅ 已验证（845个工作群事件 2026-09-03）

### 类型⑩ 人口 / 婚育 / 民生议题
**触发特征**：长期社会民生议题（人口、婚育、养老等），非单一突发事件；常跨性别/政策/经济多领域同时引爆（区别于类型②：②是"新规落地"事件，⑩是长期议题本身）
- 标准派系（已验证，基于"低生育率/年轻人不婚不育"议题 2026-09-03）：
  1. 现实压力归因派（不是不想生，是结不起、养不起、耗不起）——主流
  2. 观念变迁派（婚育从必修课变选项、个人选择优先；含"太清醒不愿让孩子受苦"亚派）——主流
  3. 性别代价派（母职惩罚/女性系统性受损；含反催生反击派"你祖宗听得见吗"）——女性社区重要
  4. 男性代价/婚恋市场派（天价彩礼挤压、男多女少、普通男退场；注意"高学历剩女更多"反转数据）——男性社区
  5. 国家危机与政策派（人口警报+从"催生"转向"发钱赋能养"；应生派边缘，公众仅约27%认同生育是社会义务）——官方主流
  6. 发钱无效/国际镜鉴派（韩国砸钱仍垫底、日本单身税争议、"国家算刺激账年轻人算生存账"）——财经圈
- 常见分歧：归因（个人自私 vs 结构性阻碍）；路径（发钱 vs 制度改革 vs 顺其自然）；性质（生育是义务 vs 权利）；谁的代价更大（性别对立）
- 常见空白：被忽略的性别一侧、城乡分化（农村彩礼=刚需 vs 城市=负担）、议题当事人本人的声音（不婚不育者自己说话）、应生派/国家责任派（公共叙事近失声）
- 平台特征（实测发现）：**性别是分裂轴心**——女性社区（母职惩罚）与男性社区（彩礼挤压）互相对立，但都反对"骂年轻人"；官媒=危机+政策，大众端=现实压力+共情，财经号=发钱无效
- 验证状态：✅ 已验证（低生育率/年轻人不婚不育 2026-09-03）

### 预测#1：纽约禁止8年级以下学生用AI（2026-09-03 预测）
- **事件**：纽约市 2026-09-02 宣布，学前班至 8 年级公立学校学生禁用生成式 AI 一年（影响约 60 万学生，全美最大学区）
- **匹配类型**：类型⑦教育（首次实测，从待验证转预测中）+ 跨类型⑥AI监管特征
- **预测派系（6 派）**：
  1. 保护支持派（主流）——AI 伤批判性思维/心理健康/人际，该禁；美国=家长草根运动+名人联署，中国=认同"低龄就该禁"

  3. 执行落地质疑派（重要）——禁令落不了地：家里照样用、数字鸿沟加剧、教师培训跟不上、怎么检测

  5. 细则派（次要）——8年级一刀切太粗，应分年龄分用途（工具性 vs 生成式）
