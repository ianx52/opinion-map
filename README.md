# 🗺️ opinion-map · 观点地图

> **研究一个话题的主流想法有几种。** 不站队，只把战场画清楚。
> 一个中立的舆论格局研究工具：一个话题上有哪些想法、谁在说、证据多硬、分歧在哪、哪些声音被忽略。

`中文` `观点研究` `舆情分析` `舆论格局` `客观中立`

---

## 为什么做这个

一个话题在公共讨论中到底有几种想法？这些想法各自有谁在说、证据有多硬、声量有多大、在哪些平台发酵、分歧在哪里、又有哪些声音被忽略？

opinion-map 把"研究一个话题的舆论格局"变成可复用的流程：**主流有哪几派、每派的主张与论证、谁在说、证据多硬、声量多大、分歧在哪、哪些声音被忽略**——一张图，看清一个话题上观点的完整分布与多元性。

## 核心能力（v0.17.0）

| 能力 | 说明 |
|---|---|
| 🎯 检索驱动播种 | 视角来自真实检索，不靠模型脑补（STORM 研究：去掉视角，引用多样性 99.83→54.36）；检索痕迹可审计 |
| 🧭 聚类维度声明 | 先声明按什么维度切分（立场/信服机制/处置主张/利益相关方），杜绝维度混切 |
| 🌳 层级化 | 大立场 → 亚派（立场相同、理由不同=亚派），不把变体当派系 |
| 🛡️ 客观性护栏 | 8 道护栏：反顺应/对立面强制检索/主流叙事警惕/中性命名/声量标注/立场披露/用户立场隔离/事实选取中立 |
| 🔍 被忽略立场检索 | 主动找"谁的声音被主流叙事忽略"，间接证据兜底不发声群体（老人/厂商/当事人） |
| 📈 演化+时效标注 | 立场是否稳定、论据是否换代；每派标最近活跃时间、地图标数据截止时间 |
| 🔊 声量来源计数 | 主流/重要/小众/边缘=等级+独立来源数+渠道列表（可复核三元组），声量≠接受度 |
| 📱 平台维度分化 | 每派标注发酵平台，识别"平台间派系分裂"；强制标注平台覆盖边界 |
| 🧭 检索饱和判定 | 连续 2 轮无新派系即饱和 + 检索词多样性检查（防假饱和），明说覆盖度，不假装全面 |
| 🏛️ 来源类型标注 | 官方/媒体/机构/个人分层，防"个人观点冒充行业共识" |
| ⏱️ 时间切片对比 | 同一话题二跑对比声量变化，观察舆论走势与格局演变 |
| 📊 视角多样性指数 | 派系/来源/平台/检索饱和状态——"地图有多全"的覆盖度量化 |
| 🧩 模块可裁剪 | 核心流程默认全开；规模预判/被忽略深度/预测/时间切片等可选模块可按需关闭 |
| ⚡ 三种模式 | 速览级（默认）/ 研究级（深度）/ 预测模式（事件太新可预判，越用越准） |
| 🧠 经验沉淀 | 每次实测回写模式库，预测靠库、库靠实测更新——**越用越聪明** |

## 快速开始

```
「观点地图」AI 对就业的影响          → 速览级（默认，快速侦察）
「研究一下中医之争，做深」           → 研究级（深度，亚派全展开+被忽略立场）
「预测下刚爆的XX事件会怎么吵」       → 预测模式（抢时间点，标【预测待校验】）
```

三种模式的完整差异见 SKILL.md「二·五 模式选择」。

## 为什么值得 Star（与同类项目的差异）

| 维度 | 本 skill | 同类典型 |
|---|---|---|
| 视角来源 | 强制检索驱动 + 检索痕迹可审计 + 被忽略立场检索 + 间接证据兜底 | STORM 只播种不找盲区 |
| 立场模型 | 维度声明 + 层级化（大立场→亚派）+ 代表区分一手/转述，立场≠情绪 | 常见二分（支持/反对）过于粗糙 |
| 客观性 | 8 道护栏 + 输出前自检清单，可对抗用户诱导/模型顺应 | 多数项目不设护栏 |
| 演化+时效 | 标注"主张出现时间 + 论据换代" + 每派最近活跃 + 地图数据截止 | 只拍当前横截面 |
| 成长性 | 模式库 + 经验沉淀 + 预测准确率跟踪 | 静态一次性工具 |
