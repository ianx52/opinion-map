# 🗺️ opinion-map · 观点地图

> **研究一个话题的主流想法有几种。** 不站队，只把战场画清楚。
> 给内容创作者的"观点侦察"：写之前先看清——哪派已说烂，哪个角度还没人占。

`中文` `观点研究` `舆情分析` `内容选题` `客观中立`

---

## 为什么做这个

做内容最怕的不是写不好，是**选题没看清战场**——你以为是新观点，其实主流窗口里早就说烂了；你以为没人提的角度，其实是被忽略的关键立场。

opinion-map 把"研究一个话题的舆论格局"变成可复用的流程：**主流有哪几派、每派的主张与论证、谁在说、证据多硬、声量多大、分歧在哪、哪个角度是空白**——一张图，写之前看清全局。

## 核心能力（v0.13.0）

| 能力 | 说明 |
|---|---|
| 🎯 检索驱动播种 | 视角来自真实检索，不靠模型脑补（STORM 研究：去掉视角，引用多样性 99.83→54.36） |
| 🧭 聚类维度声明 | 先声明按什么维度切分（立场/信服机制/处置主张/利益相关方），杜绝维度混切 |
| 🌳 层级化 | 大立场 → 亚派（立场相同、理由不同=亚派），不把变体当派系 |
| 🛡️ 客观性护栏 | 8 道护栏：反顺应/对立面强制检索/主流叙事警惕/中性命名/声量标注/立场披露/用户立场隔离/事实选取中立 |
| 🔍 被忽略立场检索 | 主动找"谁的声音被主流叙事忽略"，间接证据兜底不发声群体（老人/厂商/当事人） |
| 📈 演化标注 | 立场是否稳定、论据是否换代（"中医黑"从洋人偏见→RCT 数据，论据换了两代） |
| 🔊 声量来源计数 | 主流/重要/小众/边缘有量化依据，声量≠接受度 |
| 📱 平台维度分化 | 每派标注发酵平台，识别"平台间派系分裂"——内容平台匹配信号 |
| 🧭 检索饱和判定 | 连续 2 轮无新派系即饱和，明说覆盖度，不假装全面 |
| 🏛️ 来源类型标注 | 官方/媒体/机构/个人分层，防"个人观点冒充行业共识" |
| ⏱️ 时间切片对比 | 同一话题二跑对比声量变化，判断热点升温/降温（选题时机） |
| 📊 视角多样性指数 | 派系/来源/平台/检索轮数——"地图有多全"的覆盖度量化 |
| ⚡ 三种模式 | 速览级（默认）/ 研究级（深度）/ 预测模式（事件太新可预判，越用越准） |
| 🧠 经验沉淀 | 每次实测回写模式库，预测靠库、库靠实测更新——**越用越聪明** |

## 快速开始

```
「观点地图」AI 对就业的影响          → 速览级（默认，快速侦察）
「研究一下中医之争，做深」           → 研究级（深度，亚派全展开+被忽略立场）
「预测下刚爆的XX事件会怎么吵」       → 预测模式（抢首发，标【预测待校验】）
```

三种模式的完整差异见 SKILL.md「二·五 模式选择」。

## 为什么值得 Star（与同类项目的差异）

| 维度 | 本 skill | 同类典型 |
|---|---|---|
| 视角来源 | 强制检索驱动 + 被忽略立场检索 + 间接证据兜底 | STORM 只播种不找盲区 |
| 立场模型 | 维度声明 + 层级化（大立场→亚派），立场≠情绪 | 常见二分（支持/反对）过于粗糙 |
| 客观性 | 8 道护栏 + 输出前自检清单，可对抗用户诱导/模型顺应 | 多数项目不设护栏 |
| 演化 | 标注"主张出现时间 + 论据是否换代" | 只拍当前横截面 |
| 成长性 | 模式库 + 经验沉淀 + 预测准确率跟踪 | 静态一次性工具 |
